\## First Reflection ##



Software is a set of items forming a configuration this can be programs, documents, data and code. The engineering part adds an organisational aspect to software. Engineering uses appropriate theories and methods to solve problems while considering organisational and financial factors.





A software that has worked well for me over the years is Apples IOS on my iPhone. I've had iPhones' all my life and its always been the hardware that has failed well before the software itself gave any issues. A software that has failed/frustrated me was a java IDE called Eclipse. This software was very frustrating to use. It crashed often and the UI was cluttered and all over the place.



One example of a software failure I've experienced would have to be Apple IOS 6 Maps. Apple released their own native mapping software in 2012 to replace Google Maps on the iPhone navigation app. It had severe geographical errors, warped 3D landmarks, missing public transit data and most of the time completely lost its directions. I believe the software project was rushed trying to replace google maps, by rushing the development a lot of errors/bugs were overlooked and the software on launch wasn't ready for global use.



One example of software successes would be Instagram. Instagram was created in 2010 after the founders noticed that users only cared about sharing photos. So in response they removed all the other features and the app took off. What I think they did well was identify and a core problem or use and built the software/app around that a lot of successful applications start off by doing one thing exceptionally well.
